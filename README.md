# Wildcard Pattern

面向Minecraft 1.7.10和GTNH的AE2扩展模组。右键打开通配样板，填写名称或矿辞规则，即可批量展开AE2加工样板，减少同类材料配方的重复配置。

普通通配样板支持多条输入、输出规则；复合通配样板支持一条通配规则，并可附加最多8个固定输入。固定输入可以是物品或流体。

## 核心功能

- 手持样板右键打开配置，拖入物品或手动填写输入、输出规则，选择名称或矿辞模式并设置数量。
- 预览确认结果，按需排除材料或切换物品来源，保存后放入ME接口或GT加工输入设备使用。
- 复合通配样板可额外设置最多8个固定物品或流体输入，流体用量支持B／mB切换。

## 兼容性说明

- `v1.1.1`适配GTNH `2.9.0-RC-2`。
- `v1.0.7`适配GTNH `2.8.4`。
